# 运营台界面更新（2026-10-10）

## 布局与操作

运营台改为固定左侧分层导航、右侧数据工作区。用户学习、校园 GitHub、个人收藏组成个人工作区；官方快速访问、公共内容与项目审核独立分组。选中子页面会展开所属层级，顶部显示当前位置。数据库集合切换保留在高级视图中。

视觉采用亮色灰白底、华师大红主色与金色、紫色辅助色。统一线性 SVG 图标用于导航、统计、记录和操作按钮；表格增加头像、记录 ID 与状态徽标。进入工作区、展开导航、弹窗及请求进度增加轻量动效。成功提示 6 秒后收起，操作错误保留供查看。

桌面侧边栏可以收起；窄屏按按钮展开并独立滚动，选择页面或按 Esc 收起。表格保持列宽，在容器内横向滚动。键盘焦点、跳转内容入口和系统减少动画偏好一并处理。

设计参考 [GitHub Primer NavList](https://primer.style/product/components/nav-list/) 的紧凑分层导航，以及 [Supabase 平台文档](https://supabase.com/docs/guides/platform) 的工作区组织。图标由项目内 SVG 实现，沿用静态 HTML/CSS/JavaScript 技术栈。

## 发布与下一步

本轮仅更新运营台静态页面，数据库 schema、手机端和 AI 网关沿用现有版本。发布流程：提交到 `main` → 使用 `deploy/update-public-site.sh` 部署固定提交 → 校验线上 HTML、CSS 与模块版本。脚本保留静态文件恢复点。

管理员刷新运营台后，先在用户列表打开个人工作区，再沿侧边栏管理课程、笔记、复习卡片、计划和社区互动。项目上架在“公共内容与审核 → 项目上架审核”处理；官方小程序和官网在公共快速访问维护。

后续按实际验收记录推进：手机保存内容与管理员读回、真实项目提交与审核上架、微信真机跳转、邮件收件及正式域名恢复。这些项目分别记录实测结果，本轮界面测试与它们分开计数。
