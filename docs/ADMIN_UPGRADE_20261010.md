# 运营台改进与审计修复

日期：2026-10-10。部署和浏览器验收结果在本页末尾补记。

## 本轮变更

- 公开官网六个页脚移除运营入口；公开操作文档按管理员收藏入口描述。
- 运营台分区导航、搜索、记录数、集合数和刷新时间；红金与蓝紫作为协调辅助色，减少动态效果的系统设置受尊重。
- 七个常用分区分别提供用户、笔记、课程、工作台、卡片、学习成果和目录记录的新增动作。校园作品表单限定在校园目录。
- 读取生产集合元数据，通用字段表单提供新增、编辑、JSON 数据、文件上传和带记录 ID 确认的删除；视图读取，结构和规则通过 PocketBase 原有后台维护。
- 验收脚本覆盖管理员改笔记后普通用户读回以及 PDF 上传。授权仍由现有超级管理员和数据库规则执行。

## 审计结论的核实

本机实际复现：服务器已监听且 address 存在，Fetch 请求端口 6667 仍立即报告 `bad port`。这与 WHATWG 端口限制一致，单纯增加监听断言或重试同一端口解决不了。测试本机请求改用 Node HTTP 传输，保留状态、正文及请求头断言，生产请求保持现状。

Dart SDK 当前要求 `^3.13.4`，`dart:core` 导出 `IterableExtensions`，其中已有 `firstOrNull`。三处用法无需为此新增 collection 依赖；Context7 与本机 SDK 源码交叉核对。

`eduworkRevision` 指实际导入的四个核心模块的上游提交。网关运行方式为 `campulse-headless`；完整 Studio/Host 的部署版本与这一来源版本分别记录。

管理员口令只检查了长度和本机复用情况：13 位，与本机检查到的两个其他密码均不同。其他服务的实际口令尚未逐个核实。账号持有人下一步设置独立的随机长口令，并更新 Git 忽略的验收配置。验收脚本读取管理员凭据是授权访问方式，重点在于与普通用户及其他服务区分。

两份过期审计报告已移至本机 `.tools/audit-archive-20261010/`，可恢复，保持当前文档目录清晰。
