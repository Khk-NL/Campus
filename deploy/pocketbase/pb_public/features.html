ONE SPACE, THREE CONNECTIONS

校园日常，
放在同一个空间。

校园服务、学生作品与课程学习集中介绍；你可以按需要切换查看。

01

少找几个入口，
多一点从容。

把学校服务与学生工具重新组织，按任务查找、分类和收藏。网站或工具打开后，其登录和权限仍由原服务管理。

发现

搜索与分类

从服务名称或使用场景找到入口。

常用

收藏与快捷访问

把经常使用的校园服务放在手边。

边界

尊重原有服务

不接管学校密码，不绕过学校或第三方认证。

02

让校园作品，
遇见需要它的人。

项目展示、使用入口与 GitHub 仓库相连接。代码协作继续使用 GitHub；Campulse 关注校园里的发现、分发与使用。

展示

项目与工具

了解学生项目，再进入它的使用入口。

协作

关联 GitHub 仓库

查看源码、Issue 与贡献方式。

下一步

逐步补齐社区闭环

自主发布、贡献者招募和完整反馈协作仍在规划。

03

以一门课为线索，
留下自己的积累。

把课表、资料与笔记串联起来。课程问答使用你选定的资料，个人笔记仍由 Campulse 保存。

安排

课表与 CSV 导入

导入预览、重复检测和时间冲突检查。

积累

课程笔记与云端保存

按账号隔离，跨设备通过重新读取获得更新。

理解

基于资料的 AI 问答

网关验证身份与资料归属后调用 ChatECNU。

云端提供全文检索、引用、测验、闪卡、导图与智能体对话。问答会将问题与选定正文发送给模型服务；跨设备更新通过重新读取云端内容完成。

从你的下一件校园小事开始。
