# 主题与前端文案调整

日期：2026-10-09。

## 主题设置

入口：「我的 → 设置 → 主题色」。

- 默认配色为品牌红、柔金黄和少量蓝紫。
- 提供红金、蓝紫、紫粉、琥珀四组预设。
- 主色和辅助色支持六位十六进制输入，例如 `#A41F35`。
- 弹窗内预览，点击「应用配色」后全局生效；取消保留原设置。
- 「恢复默认」清除自定义偏好。设置保存在本机，重新启动读回。
- 自定义颜色作为配色种子，由 Flutter 生成亮暗主题的文字与背景组合。极亮、极暗颜色的文字对比度已测试。
- 首页、应用筛选及闪卡使用共享辅助色，AppBar、导航与主要按钮随主色更新。产品标志保持品牌样式。

实现方式按 [Flutter ColorScheme.fromSeed 官方文档](https://api.flutter.dev/flutter/material/ColorScheme/ColorScheme.fromSeed.html)核对。沿用已有 SharedPreferences，主色和辅助色在同一条偏好中保存。

## 文案
