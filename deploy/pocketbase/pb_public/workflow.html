HOW CAMPULSE WORKS

入口清晰。
数据各归其位。

登录与身份

App 通过 HTTPS 连接 PocketBase。普通用户账号与管理员账号分开，注册邮件验证仍按服务配置执行。

使用校园服务

从应用目录选择网站、工具或项目。外部服务由其自身管理登录与权限；Campulse 不接管学校密码。

保存课程与笔记

个人数据写入归属当前账号的记录。重新加载时读取云端内容，其他普通用户不能访问这些记录。

发起 AI 问答

选择课程资料并提问 → 网关验证身份和资料范围 → ChatECNU 返回回答。模型密钥只保存在服务器。

版本发布

源码推送 GitHub → 自动检查与构建 APK → 发布 GitHub Release。用户从官网跳转下载。
