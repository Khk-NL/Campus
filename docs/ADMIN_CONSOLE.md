# 运营台与手机数据查看

## 访问入口

管理员使用自行收藏的运营入口。公开官网导航仅提供产品与社区页面；访问地址由运营人员保管。正式域名备案恢复后，同步更新收藏地址。

运营台使用当前站点的 `/api` 连接 PocketBase，复用已有数据库和管理员身份。2026-10-09 已部署并完成浏览器登录、用户内容筛选和作品表单点击验收。

登录使用 **PocketBase 超级管理员** 邮箱和密码，与阿里云账号、Linux SSH 账号分别管理。现有测试配置保存在 Git 忽略的 `.tools/remote-acceptance.env`；凭据由账号持有人保管。普通用户在手机 App 注册或登录自己的账号。

管理员使用独立的随机长口令；验收脚本需要管理员权限时，读取这一管理员凭据。普通测试账号和其他服务分别设置密码。入口路径的公开性与认证权限分别管理，删除导航链接用于减少访客发现入口。

## 从手机操作到电脑查看

1. 手机安装本轮 GitHub 云构建 APK，在「我的」登录普通账号。
2. 打开个人课程，新建或编辑笔记，点击保存；或者在首页新建计划、完成计划。
3. 电脑打开运营台并登录管理员，进入「用户」，点击该账号的「查看内容」。
4. 在「笔记」查看标题、课程、正文和更新时间；切换「计划与工作台」查看待办与已完成数量及每项内容。点击刷新读取当前云端记录。
5. 切换「课程」「复习卡片」「学习成果」查看该用户的其他内容；清空用户 ID 可查看分区内全部记录。标题、邮箱、正文或 ID 支持搜索，列表每页 25 条。

手机笔记、课程、计划、复习和知识工作台成果写入 PocketBase。主题色、昵称、头像样式和收藏目前按设备保存。运营台展示的是保存记录；在线状态、最后活跃时间和操作审计属于后续开发。

## 校园 GitHub 管理

1. 点击「发布校园作品」，填写名称、开发者、使用地址、GitHub 仓库、简介及标签。
2. 勾选「发布到应用目录」并保存；保留为草稿时，可稍后继续编辑和发布。
3. 手机刷新应用目录，新作品进入校园作品与快速入口的对应视图，GitHub 链接指向项目仓库。
4. 运营台中可通过「作品设置」编辑 Web 作品、发布或转为草稿。「新增目录记录」及通用「编辑」表单按字段维护其他校园服务；复杂 launchTarget 使用 payload JSON 编辑。

Git 分支、提交、Issue、PR 和 CI 继续由 GitHub 管理。Campulse 管理校园作品的目录、使用入口及展示状态。

## 用户和个人内容维护

每个分区有对应的新增入口与描述。用户、笔记、课程、工作台、卡片和成果支持查看、新增、编辑与删除。表单读取生产集合元数据，JSON 字段提供可折叠编辑器；笔记支持正文和 PDF 上传。用户邮箱与 Verified 可由管理员维护，新用户创建填写两次密码；现有密码调整在原数据库后台完成。

「数据分区」同时列出服务器返回的其他集合，通用记录表单覆盖已有数据库集合，视图提供读取。「结构与权限」进入 PocketBase 原有后台维护字段、索引及访问规则。当前管理员本就具备全库权限；运营台复用这一身份，普通用户隔离规则保持原样。

永久删除需要输入目标记录 ID，确认页说明备份恢复和级联影响。个人数据维护应按用户请求进行。操作审计和分级运营角色继续列为后续开发。

| 用户 | `users` | 记录 ID |
