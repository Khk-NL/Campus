# 运营台与手机数据查看

## 访问入口

- 运营台：`https://campus.allezafrique.cn/admin.html`
- PocketBase 数据库后台：`https://campus.allezafrique.cn/_/`
- 正式域名备案恢复后，同样的页面路径使用 `https://campus.scsldr.cn`。

运营台使用当前站点的 `/api` 连接 PocketBase，复用已有数据库和管理员身份。代码已完成，首次公网部署和页面点击结果将在本页末尾记录。

登录使用 **PocketBase 超级管理员** 邮箱和密码，与阿里云账号、Linux SSH 账号分别管理。现有测试配置保存在 Git 忽略的 `.tools/remote-acceptance.env`；凭据由账号持有人保管。普通用户在手机 App 注册或登录自己的账号。

## 从手机操作到电脑查看

1. 手机安装本轮 GitHub 云构建 APK，在「我的」登录普通账号。
2. 打开个人课程，新建或编辑笔记，点击保存；或者在首页新建计划、完成计划。
3. 电脑打开运营台并登录管理员，进入「用户」，点击该账号的「查看内容」。
4. 在「笔记」查看标题、课程、正文和更新时间；切换「计划与工作台」查看待办与已完成数量及每项内容。点击刷新读取当前云端记录。
5. 切换「课程」「复习卡片」「学习成果」查看该用户的其他内容；清空用户 ID 可查看分区内全部记录。列表每页 25 条。

手机笔记、课程、计划、复习和知识工作台成果写入 PocketBase。主题色、昵称、头像样式和收藏目前按设备保存。运营台展示的是保存记录；在线状态、最后活跃时间和操作审计属于后续开发。

## 校园 GitHub 管理

1. 点击「发布校园作品」，填写名称、开发者、使用地址、GitHub 仓库、简介及标签。
2. 勾选「发布到应用目录」并保存；保留为草稿时，可稍后继续编辑和发布。
3. 手机刷新应用目录，新作品进入校园作品与快速入口的对应视图，GitHub 链接指向项目仓库。
4. 运营台中可编辑 Web 作品、发布或转为草稿。原生 App、小程序以及复杂校园服务记录通过页面顶部的数据库后台维护。

Git 分支、提交、Issue、PR 和 CI 继续由 GitHub 管理。Campulse 管理校园作品的目录、使用入口及展示状态。

## 用户和个人内容维护

运营台提供按用户查看内容的入口。更深入的用户资料维护、笔记编辑和数据处理使用 PocketBase 原有后台：选择对应集合，按用户 ID 查找记录，再打开编辑。个人数据维护应按用户请求进行；数据库规则继续隔离普通账号的数据访问。

| 内容 | PocketBase 集合 | 用户归属字段 |
| --- | --- | --- |
| 用户 | `users` | 记录 ID |
| 笔记及 PDF | `course_notes` | `owner` |
| 个人课程 | `user_courses` | `owner` |
| 计划与工作台 | `study_workspaces` | `owner` |
| 复习卡片 | `course_review_cards` | `owner` |
| 成果与对话 | `course_artifacts` | `owner` |
| 校园服务、作品与公开目录 | `campus_content` | 管理员维护 |

## 部署方式

`deploy/update-public-site.sh` 接受完整源码提交号，下载本项目 10 个官网及运营台文件，校验 JavaScript 语法，备份当前同名文件后更新 PocketBase 的 `pb_public`。数据库、AI 网关和其他网站保持现状，静态页面生效后即可访问。
