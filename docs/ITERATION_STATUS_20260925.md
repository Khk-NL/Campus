# 本轮功能落实与边界

| 反馈 | 本轮已落实 | 尚未完成 |
| --- | --- | --- |
| 学习过程记录拥挤 | 按“问题与观察 / 证据与资料 / 智能体与学习助手 / 结论与下一步”分段折叠；保存提示区分本机与试点账号。 | 手机实机视觉验收、进一步压缩字段。 |
| 课表缺导入与参考项目能力 | 个人课程 CSV 预览、逐行选择、重复与时间冲突提示、教学周/单双周/自定义周、多星期排课；存到 PocketBase `user_courses`，普通用户隔离。 | 官方教务一键导入、时间型 CSV 无损转换、调课/停课、考试、编辑及撤销。不能宣称覆盖 `sp-study-courses` 全部功能。 |
| 应用混成一块 | “快速入口”保留官方和学生可用服务；“校园作品”集中学生项目，收藏状态共用。 | 项目发布、审核、反馈与贡献流程。当前不是 GitHub 代码托管服务。 |
| EduWork 未接入 | 核对开源源码、现有 Campulse 学习空间/笔记边界与接口，记录服务端网关的接入要求；未伪造生成结果。 | 真正的 AI 问答、知识索引、测验/闪卡/导图生成与同步。EduWork 当前公开实现依赖桌面 DSH 宿主，仍需可授权、手机可访问的网关和模型配置。见 [开源项目参考与使用说明](OPEN_SOURCE_USAGE.md)。 |
| 不仅按课程，也按智能体 | 新增“按智能体”视角，同一学习空间中跨课程聚合已关联记录，可打开与继续编辑；不复制数据。 | 智能体远程运行、跨设备实时同步冲突处理。 |

本轮数据仍以 PocketBase 作为 Campulse MVP；学校官方平台和数智学研没有成为数据源。`dire.muedu.org/student` 的登录后页面未完成可靠实测，因此不能把其具体功能集、接口或授权方式写成已验证事实。后续若有获授权的网关和测试账号，应先完成最小问答/引用链路，再逐项扩充产物能力。
