# 用户工作区与公共目录（2026-10-10）

## 数据归属

| 内容 | 归属与存储 | 运营台入口 |
| --- | --- | --- |
| 账号、昵称 | `users` | 用户列表 → 打开工作区 |
| 课程、课表 | `user_courses.owner`；课表沿用同一批课程的时间规则 | 学习 → 课程 / 课程表 |
| 笔记、PDF、复习卡片、学习成果 | `owner + courseId`；附件继承笔记权限 | 学习 → 课程 → 笔记 / 卡片 / 成果 |
| 计划、学习记录、证据、知识库、Wiki、智能体配置 | `study_workspaces.owner`，内容位于工作台 payload | 学习 → 计划与工作台 |
| 个人通知、个人待办 | `campus_content.owner`，分别为 `announcement` / `task` | 学习 → 个人通知 / 个人待办 |
| 个人仓库 | `forge_repositories.owner` | 校园 GitHub → 个人仓库 |
| 收到的讨论与回复 | 项目归当前用户，发言者归其他用户 | 个人仓库 → 收到的讨论 / 回复 |
| 社区项目 | 项目作者持有记录；公开发现采用华师大审核条件 | 校园 GitHub → 社区项目仓库 |
| 参与的讨论与回复 | 发言者归当前用户，项目归其他用户 | 社区项目仓库 → 参与的讨论 / 回复 |
| Star | `forge_stars.owner + repository` | 社区项目仓库 → Star 关注 |
| 官方小程序、官网 | 全校共用 `campus_content` 目录，`owner` 留空 | 公共快速访问 |
| 收藏 | `user_favorites.owner + board + entryKey`，唯一索引限制重复 | 用户工作区 → 个人收藏 |
| 校园公告、活动 | 保留公共来源，`owner` 留空；定向通知使用个人通知 | 公共内容与审核 → 公告 / 活动 |

课程空间和社区采用关联查询；同一条数据可以从不同工作区查看。高级数据库视图保留现有全库记录维护入口。

## 移动端变化

- 正式启动装配直接连接远程仓库。原模拟目录、身份和离线回退仓库移入 `test/fixtures`，供自动测试使用。
- 新建本机学习工作台从空内容开始。旧的两条原样示例任务在读取时过滤；修改过的任务、关联学习记录及原磁盘文件保留。
- PocketBase 请求失败进入连接提示并提供重试，加载身份后遇到目录连接失败保留账号。
- 登录用户的收藏读取、增删走 PocketBase；切换账号隔离本地缓存，退出后使用访客收藏。旧的共享本机收藏保留为访客收藏，账号归属由用户自行重新收藏确认。
- 收藏云端写入成功后更新选择状态；失败显示重试提示。当前离线收藏缓存用于查看，离线写入采用失败提示。
- 原有服务端测试账号和管理员可维护记录保留。迁移前的无归属待办仍留在数据库，管理员填写 `owner` 后由对应用户读取。

## 迁移与部署

1. 备份现有 `pb_data` 与迁移目录。
2. 执行 `1790210012_user_relationships.js`：建立用户收藏集合，给目录增加可选用户关系，个人待办和定向通知按用户隔离。
3. 更新运营台 HTML、CSS、模块文件。
4. 使用 main 分支 GitHub Actions 构建 APK，再做设备点击验收。

全新数据库仍按安装脚本先执行基础迁移。增量生产更新使用 `deploy/update-community.sh SOURCE_COMMIT 1790210012_user_relationships.js`，静态页面使用 `deploy/update-public-site.sh SOURCE_COMMIT`。
