# 导航、待办与个性化验收

日期：2026-10-09。

## 本轮变化

- 课程的一级切换为「课程列表 / 课程表」，课程内部保留智能体功能。
- 应用的标签默认收起，展开后按学习与课程、校园生活、作品与工具、校务服务、其他标签分组。分组由现有条目的类型和标签生成，空组不显示；收起后仍可看到当前选中的标签。
- 首页「我的计划」改为主要卡片，可新增、编辑和完成待办。编辑器复用课程计划中的日期、优先级、子任务、标签和预计用时功能。完成后归档，通过「全部计划」里的「已完成」查看。
- 首页待办沿用课程计划的存储选择：已登录时使用 PocketBase，本机模式使用已有本地仓库。保存前读回工作区，保留其他课程内容；保存失败提示重试并保留原状态。返回首页及从完整计划页返回时刷新。
- 我的页面将设置、关于分别折叠，增加昵称和四种头像样式。个性化保存在本机，按账号隔离，重启后读回。
- 保留品牌红，增加统一的雾蓝和蓝紫辅助色。课程、首页分区和筛选卡片使用主题色，四个主页面切换加入轻量淡入，待办列表伸缩和折叠加入过渡；新增动画遵循系统减少动画设置。
